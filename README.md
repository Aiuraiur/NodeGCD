# Node GCD：图节点上的广义类别发现

**Node GCD**（Generalized Category Discovery on Graphs）是一个面向**图节点分类**的广义类别发现（GCD）方法：在仅有少量已知（seen）类别节点带标签的情况下，同时完成
(1) 对已知类别节点的分类，以及 (2) 对未知（novel）类别节点的**自动类别发现**——包括未知类别数量估计与聚类结构的挖掘。

本项目源自硕士开题研究，代码基于 PyTorch + DGL 实现，GAT 作为骨干编码器，采用原型对比学习框架。

## 1. 问题定义

给定图 \(\mathcal{G} = (\mathcal{V}, \mathcal{E}, \mathbf{X})\)，其中 \(\mathcal{V}\) 为节点集合，\(\mathcal{E}\) 为边集合，\(\mathbf{X} \in \mathbb{R}^{N \times d}\) 为节点特征。全部类别集合 \(\mathcal{C} = \mathcal{C}_s \cup \mathcal{C}_n\)，其中 \(\mathcal{C}_s\) 为已知（seen）类别，\(\mathcal{C}_n\) 为未知（novel）类别，且 \(\mathcal{C}_s \cap \mathcal{C}_n = \emptyset\)。

训练阶段只有 \(\mathcal{C}_s\) 中的少量节点带有标签（每个 seen 类别约 10% 训练 + 10% 验证），其余节点（含全部 novel 类节点）均无标签。方法需要解决：

1. **类别发现**：自动估计 novel 类别的数量 \(|\mathcal{C}_n|\)，并为所有无标签节点挖掘聚类结构；
2. **联合分类**：在发现的聚类结构上，对 seen 与 novel 节点同时获得准确的类别划分。

**评价指标**：对学到的节点嵌入执行 KMeans 聚类，再以匈牙利算法将聚类结果与真实标签对齐，分别报告总体（Overall）、已知类（Seen）与未知类（Novel）聚类准确率；同时报告预测的类别总数 \(n_{\text{pred}}\) 以衡量类别数量估计的质量。

## 2. 创新点与挑战

本方法凝练为**两个创新点**，分别对应任务中的**两个核心挑战**。

### 创新点一：渐进式多原型对比学习（Progressive Multi-Prototypical Contrastive Learning）

**对应的挑战一：ID（seen）与 OOD（novel）类内方差不平衡。**

在开放世界半监督训练中，已知类别节点通过监督损失会迅速形成**紧凑的簇结构**；而未知类别节点由于缺乏任何监督信号，嵌入保持**高度分散**。这种"ID 紧凑、OOD 松散"的类内方差不平衡，会导致对比学习中的负样本空间被严重扭曲：松散的 novel 节点容易被"吸"进 seen 类簇，或在聚类时被切成碎片，从而损害 novel 类别的发现质量（体现在 baseline 中普遍存在的"Seen 高、Novel 极低"现象）。

**解决思路**：让每个类别在训练初期由 \(M\) 个原型刻画（允许较大的类内方差），随后在训练过程中**渐进式地把最相似的原型两两合并**，直至每类收敛为 1 个原型（类内方差小）。这样所有类别（seen 与 novel）都遵循"起点方差大、终点方差小"的同一条演化路径，从机制上避免 ID/OOD 类内方差不平衡。具体包括：

- **两级原型对比损失**：节点-原型（N2P）与原型-类中心（P2C）两级对比，配合随 epoch 退火的温度系数使分配逐步 sharpen；
- **多视图增强**：利用 GAT 多头注意力机制，将不同注意力头的输出（NCLA 风格）或不同层的输出（negMIX 风格）作为同一节点的多个视图，无需额外图增强开销；
- **渐进式原型合并**：每间隔若干 epoch，对每类中余弦相似度最高的一对活跃原型进行合并（按原型重要性权重 α 加权，或按节点软分配的质心合并），并引入 **mask-aware 机制**——被合并掉的原型立即退出 N2P/P2C 的正负样本计算，保证损失的严格一致性。

### 创新点二：图结构感知的新类数量估计（Graph-Structure-Aware Novel Class Number Estimation）

**对应的挑战二：novel 类别的数量未知。**

聚类任务中类别数量未知是 GCD 的核心难点。传统方法依赖肘部法则、轮廓系数等**纯嵌入空间**的聚类质量指标，完全忽略了节点之间的**图结构信息**（邻居关系、社区结构）。图上的类别划分天然具有社区属性，利用图结构可以给出更可靠的类别数量信号。

**已实现的方案**：为候选 novel 类别数 \(K\) 定义联合评分

\[
I(K) = w_1 \cdot \hat{Q}(K) + w_2 \cdot \hat{S}(K) + w_3 \cdot \hat{A}(K)
\]

其中 \(\hat{Q}(K)\) 为归一化**图模块度**（modularity，衡量簇内边密度相对随机网络的增益），\(\hat{S}(K)\) 为归一化**图分离度**（separation，衡量簇内边与簇间边的比例），\(\hat{A}(K)\) 为归一化的**已标注节点对齐准确率**（对每个候选 \(K\) 做 KMeans 后，用匈牙利算法将聚类与 seen 类标签对齐，计算 labeled 节点上的准确率）。候选 \(K\) 的搜索采用 **Brent 加速的二分式搜索**（以 Calinski-Harabasz 指数为代理目标快速定位区间）再配合局部枚举。类别数量估计与嵌入学习**交替迭代**：训练开始时做初始估计，之后每隔固定轮数重新估计并热启动原型（ProtoGCD 式的相互增强范式）。

**未实现的部分（未来工作）**：idea 文档中规划的**强化学习框架**目前**尚未实现代码**。其设想为：将类别数量估计建模为序贯决策问题——状态 \(S\) 包含当前新类数量与聚类结构统计特征，动作 \(A\) 为对新类数量的调整，奖励 \(R\) 由聚类质量与估计误差给出，通过强化学习在训练过程中自适应地搜索最优类别数量。该部分作为论文的延伸工作，暂未包含在本代码库中。

## 3. 方法详述

### 3.1 总体框架

```
                    ┌─────────────────────────────────────────────┐
                    │  GAT 编码器（多头注意力 → 多视图嵌入）          │
                    └───────────────┬─────────────────────────────┘
                                    │ [N, V, D]
     ┌──────────────────────────────▼──────────────────────────────┐
     │  阶段一：SupCon 无监督预训练（warmup）                         │
     │  所有节点（seen+novel）平等参与自监督对比，平衡类内方差          │
     └──────────────────────────────┬──────────────────────────────┘
                                    │
     ┌──────────────────────────────▼──────────────────────────────┐
     │  阶段二：迭代训练                                             │
     │  ┌─────────────────────────────────────────────────────┐   │
     │  │ ① K 估计：联合指标 I(K) + Brent 搜索（周期性 refine）   │   │
     │  │ ② 原型热启动：类感知多原型初始化 / 单原型初始化          │   │
     │  │ ③ 原型分配：w → q → 伪标签（匈牙利对齐）                │   │
     │  │ ④ 损失：N2P + P2C（mask-aware，温度退火）              │   │
     │  │ ⑤ 类总体原型：α 加权聚合 + EMA（K 变化时重置）          │   │
     │  │ ⑥ 渐进合并：每 merge_interval 轮合并最相似原型对        │   │
     │  └─────────────────────────────────────────────────────┘   │
     └──────────────────────────────┬──────────────────────────────┘
                                    │
     ┌──────────────────────────────▼──────────────────────────────┐
     │  评估：KMeans + 匈牙利对齐 → Overall / Seen / Novel ACC       │
     └─────────────────────────────────────────────────────────────┘
```

### 3.2 多视图 GAT 编码器

编码器为多层 GAT（`networks/gat.py`、`networks/model.py`），输出经 L2 归一化的节点嵌入。视图构造支持两种方案（对应 idea 文档中的两个备选）：

- **`gat_view='head'`（默认，NCLA 风格）**：将多头 GAT 不同注意力头的输出作为同一节点的不同视图，视图数 \(V\) = 头数；
- **`gat_view='layer'`（negMIX 风格）**：将 GAT 不同层的中间输出作为不同视图，视图数 \(V\) = 层数。

多视图既服务于 N2P/P2C 对比损失（跨视图增强），也用于原型分配中多视图概率的平均。

### 3.3 原型表示与原型管理

- **`ProtoClassifier`**（`networks/prototype.py`）：维护可学习原型矩阵 \(\mathbf{P} \in \mathbb{R}^{V \times (C \cdot M) \times D}\)，其中 \(C\) 为类别数（含 seen 与预测的 novel 类），\(M\) 为每类原型数，\(D\) 为嵌入维度。
- **`PrototypeManager`**（`networks/prototype_manager.py`）：维护两个关键状态：
  - **活跃掩码 `prototype_mask`** \([C, M]\)：记录每个原型是否活跃，被合并掉的原型掩码置 0；
  - **重要性权重 `alpha`** \([C, M]\)：每个原型对其类别的贡献权重，由节点分配统计量（硬计数或软计数）归一化得到。
- **类总体原型**：每个类别的总体原型由该类活跃原型按 α 加权聚合得到，并在训练中做**指数滑动平均（EMA）**更新；当 K 估计结果发生变化时重置 EMA，避免新旧类别空间的污染。

### 3.4 损失函数

#### (1) SupCon 预训练损失（warmup 阶段）

训练开始的 \(T_{\text{warm}}\) 个 epoch，采用 SimCLR 风格的自监督对比损失对编码器进行预训练：以 GAT 多头注意力输出作为多个视图，正样本为同一节点的不同视图，负样本为其他节点。**所有节点（seen + novel）平等参与**，使 novel 类节点在进入原型学习前获得不逊于 seen 类节点的表示质量，从源头缓解类内方差不平衡。大图上支持随机子采样以避免 \([NV \times NV]\) 相似度矩阵的内存溢出。

#### (2) N2P 损失：节点-原型对比（`losses/n2p_loss.py`）

给定视图 1 中节点 \(i\) 作为锚点，其正样本为**同一视图与跨视图中同类别的所有活跃原型**，负样本为所有其他类别的原型：

\[
\mathcal{L}_{\text{N2P}} = -\log \frac{\sum_{v,k} w(i,k,v) \cdot e^{\langle \mathbf{h}_i, \mathbf{p}_{c(i),k}^v \rangle / \tau_t}}{\sum_{v,k} w(i,k,v) \cdot e^{\langle \mathbf{h}_i, \mathbf{p}_{c(i),k}^v \rangle / \tau_t} + \sum_{c' \ne c(i), v, k} e^{\langle \mathbf{h}_i, \mathbf{p}_{c',k}^v \rangle / \tau_t}}
\]

其中 \(w(i,k,v)\) 为类内原型加权（softmax over 正样本相似度，可选开启），温度系数随训练退火：

\[
\tau_t = \tau \cdot \gamma^{t}
\]

随着 epoch 增大温度下降，分配分布逐渐 sharpen。**mask-aware**：被合并的原型通过掩码从分母与正样本加权中剔除。

#### (3) P2C 损失：原型-类中心对比（`losses/p2c_loss.py`）

以每个活跃原型为锚点，其正样本为所属类别的总体原型（所有视图），负样本为其他类别的总体原型：

\[
\mathcal{L}_{\text{P2C}} = -\frac{1}{|A|} \sum_{a \in A} \log \frac{\sum_v e^{\langle \mathbf{p}_a, \bar{\mathbf{p}}_{c(a)}^v \rangle / \tau}}{\sum_v e^{\langle \mathbf{p}_a, \bar{\mathbf{p}}_{c(a)}^v \rangle / \tau} + \sum_{c' \ne c(a), v} e^{\langle \mathbf{p}_a, \bar{\mathbf{p}}_{c'}^v \rangle / \tau}}
\]

该损失将每个原型拉向其类中心并推离其他类中心，使多原型在"松散刻画"的同时保持类别间判别力。支持两种分母口径：逐视图对比（separate view）与跨视图联合分母。

#### (4) 辅助损失（按需开启，arXiv 配置默认启用）

- **线性头 CE**（`ce_weight`）：在 seen 类真实标签上监督编码器；
- **原型导向 CE**（`proto_ce_weight`）：梯度直接流入原型，增强原型判别力；
- **类中心导向 CE**（`center_ce_weight`）：用 EMA 类中心指导编码器；
- **类内原型多样性正则**（`proto_div_weight`）与**类间中心多样性正则**（`center_div_weight`）：防止原型/类中心坍缩；
- **边际熵正则**（`entropy_weight`）：\(\mathcal{L}_{\text{ent}} = \sum_c \bar{q}_c \log \bar{q}_c\)，最小化它等价于最大化边际类别分布的熵，防止所有节点被分配到少数类别（防坍缩，ProtoGCD Eq.13 风格）。

总损失：

\[
\mathcal{L} = \mathcal{L}_{\text{N2P}} + \lambda_{\text{p2c}} \cdot \mathcal{L}_{\text{P2C}} + \lambda_{\text{ce}}\mathcal{L}_{\text{CE}} + \lambda_{\text{pce}}\mathcal{L}_{\text{PCE}} + \cdots
\]

其中 P2C 的平衡系数 \(\lambda_{\text{p2c}}\) 支持**自适应模式**（按 \(\mathcal{L}_{\text{N2P}} / \mathcal{L}_{\text{P2C}}\) 的比值动态缩放）与**固定模式**。

### 3.5 渐进式原型合并

- **触发条件**：多原型阶段内，每隔 `merge_interval` 个 epoch 执行一次；
- **合并规则**：对每个类别，在活跃原型中找出余弦相似度最高的一对，按 α 权重合并为一个原型（`merge_mode='alpha'`），或按其节点软分配质心的并集计算（`merge_mode='w_centroid'`）；
- **掩码更新**：被并入的原型 `mask=0`，立即退出 N2P/P2C 与分配计算（mask-aware）；
- **阶段设计**：仅在**前 `multi_proto_rounds` 次 K 预测轮**使用多原型，后续轮次直接以单原型热启动，训练后期快速收敛；多原型阶段内每隔 `merge_interval` 个 epoch 渐进合并一次。

### 3.6 新类数量估计（K 估计）

- **评分函数**：对候选 novel 数 \(K\)，在嵌入上做 KMeans 后计算归一化模块度 \(\hat{Q}(K)\)、归一化分离度 \(\hat{S}(K)\)、归一化 labeled 对齐准确率 \(\hat{A}(K)\)（可选第 4 项轮廓系数），加权得到联合指标 \(I(K)\)；
- **搜索策略**：以 Calinski-Harabasz 指数为代理目标，用 **Brent 有界标量优化**快速定位候选区间，再在区间邻域内精确枚举；
- **与训练的交替**：`main_epoch=0` 时做初始估计；之后每隔 \(k_{\text{refine}}\) 轮重新估计。估计更新后用当前嵌入**热启动原型**（类感知初始化 `class_kmeans`：seen 类在类内 labeled 节点上做 KMeans 得到 \(M\) 个子原型；novel 类经全局 KMeans + 匈牙利对齐定位后，在对应簇内再做 KMeans）；
- **估计辅助能力**：估计的类别数决定原型的有效类别维度，训练中按需动态扩展/收缩，实现嵌入学习与类别数量预测的相互增强。

## 4. Baselines

对比方法共 **8 个**（OpenCon 与 ORCA 因年代较早、框架较旧未列入对比）：

| 方法 | 出处 | 核心思想 |
| --- | --- | --- |
| **OpenIMA** | ICDE 2024 | 开放世界节点分类的 Imbalance-Aware 方法，通过缩减偏差的伪标签做对比学习 |
| **OODGAT** | KDD 2022 | 分离注意力与置信度损失联合训练，显式建模 OOD 节点检测 |
| **OpenLDN** | ECCV 2022 | ORCA 的后继，双分支结构与伪标签对比学习发现新类 |
| **SimGCD** | ICCV 2023 | 参数化分类头的 GCD 基线，去掉聚类后处理、端到端训练 |
| **ProtoGCD** | TPAMI 2025 | 统一无偏原型学习，原型重初始化 + 熵正则防坍缩 |
| **GOLD** | ICLR 2025 | 隐式对抗潜变量生成的图 OOD 检测框架 |
| **negMIX** | WWW 2025 | 对嵌入做负样本 Mixup 增强 OOD 泛化，开放集节点分类 |
| **RLCD** | ICML 2025 | 互惠学习 + 类分布正则化，缓解 GCD 中的 seen 类偏置 |

### 5.5 结果分析

1. **Overall 指标**：Node GCD 在 7 个数据集中的 3 个取得最优（cora、citeseer、coauthor_cs），其中 citeseer 上领先第二名约 9.3 个百分点（0.6673 vs 0.5743）；在 wikics 上排名第二。
2. **Novel 指标**：Node GCD 在 citeseer、amazon_photos、coauthor_cs 三个数据集上取得最优，novel 类别发现能力是主要优势所在——这直接受益于创新点一（渐进式多原型对比学习）对 ID/OOD 类内方差平衡的处理。
3. **Seen/Novel 平衡**：对比 SimGCD、ProtoGCD、RLCD 等"Seen 极高（0.85+）但 Novel 很低（0.2~0.5）"的明显偏置现象，Node GCD 的 Seen/Novel 指标更加均衡（如 cora 上 0.7667 / 0.5390），说明渐进合并机制在保持 seen 类别判别力的同时，有效保护了 novel 类别的聚类结构。
4. **类别数量估计**：在 amazon_photos 上精确命中 GT（8.00 vs 8），cora 上接近 GT（6.20 vs 7）；对比 SimGCD/ProtoGCD/RLCD 等在 amazon_photos 上估计为 11.20 的明显过估，图结构联合指标对类别数量的估计更加稳健。
5. **arxiv 大图**：OpenIMA 在 arxiv 上整体领先，说明超大规模图上不平衡感知设计仍有其优势；Node GCD 在 arxiv 上的 K 估计方差极小（21.10±0.30），估计稳定性突出。

## 7. 快速开始

### 依赖

- Python 3.8+，PyTorch ≥ 1.13，DGL，scikit-learn，scipy，numpy
- arxiv 数据集额外需要 `ogb`

### 运行

```bash
# 默认配置（分阶段多原型 + 分视图平均损失），10 个种子
python train.py --dataset cora

# 指定设备
python train.py --dataset citeseer --device 0

# 单种子调试
python train.py --dataset amazon_photos --single_run --seed 1

# fixed-K 消融（使用真实类别数，不做 K 估计）
python train.py --dataset cora --no_estimate_k
```

### 默认配置

| 配置 | 说明 |
| --- | --- |
| `B1`（默认） | 分阶段多原型（仅前 `multi_proto_rounds` 次 K 预测使用多原型，后续单原型）+ 分视图平均损失；arxiv 上自动附带专用配置 |

**arxiv 专用配置说明**：在 arxiv 数据集上会自动启用专用配置（代码中 `ARXIV_B1_OVERRIDES`，可用 `--no_arxiv_b1_override` 关闭做消融），主要包括：

- **额外的辅助损失**：seen 标签线性分类头 CE（`ce_weight=0.5`）、原型导向 CE（`proto_ce_weight=1.0`）、类中心多样性正则（`center_div_weight=1.0`）、固定 P2C 平衡（`p2c_balance_mode=fixed`，`p2c_weight=2.0`）；
- **容量与优化设置**：`hidden_dim=256`、`lr=0.003`、`weight_decay=1e-4`、特征/注意力 dropout=0.3、`proto_tau=0.5`、`ema_momentum=0.5`、`proto_init=labeled`；
- 该设计参考了对比 baseline 中 arxiv 使用额外损失项的做法（如 OpenIMA 在 arxiv 上增加最近邻伪标签对 BCE 一致性损失），在 arxiv 上 Overall ACC 达到约 **37%**（即 `result.xlsx` 中 arxiv 的 0.3756）。
- 除 arxiv 外的 6 个数据集使用 `DATASET_CONFIGS` 中的各自默认配置，不启用上述专用项。

### 关键参数

- `--n_prototypes`：每类原型数 \(M\)（默认取数据集配置，通常 3~10）
- `--merge_interval`：渐进合并间隔（epoch）
- `--proto_tau` / `--gamma`：N2P/P2C 温度与退火系数
- `--k_refine_rounds` / `--max_novel_k`：K 估计轮数与 novel 类别数上限
- `--k_score_weights`：联合指标权重（模块度, 分离度, labeled 精度[, 轮廓系数]）
- `--proto_init`：原型初始化模式（`class_kmeans` 为类感知初始化）
- `--ema_momentum`：类总体原型 EMA 系数
- `--mask_aware` / `--no_mask_aware`：合并失活的原型是否参与损失
